# NetworkCheck
快速地，本地网络检测和简单修复

排查 macOS / Windows 上因加速器、VPN、代理软件异常退出而残留的网络问题。

**当前版本：v1.0**

## 项目文件

- `Windows/NetworkCheck.py` — 主程序（Python 3.8+，纯标准库）
- `Mac/NetworkCheck.command` — macOS 启动器

## 使用方法

### Windows

需先安装 Python 3.8+（python.org，安装时勾选 Add Python to PATH），然后：

```
python NetworkCheck.py
```

目前仓库未提供预编译的 `.exe`。如需独立可执行文件，可在 Windows 环境下自行打包：

### macOS

直接双击运行。

## 功能说明

程序启动后自动执行检测，覆盖 14 个检查项：

系统代理、各网络服务代理、WinHTTP 代理、环境变量代理、VPN 配置、默认路由、虚拟网卡、DNS 配置、代理端口监听、相关进程、hosts 文件、启动项、系统扩展、网络扩展。

检测完成后显示菜单：

```
1) 再次检测
2) 修复（先展示动作，确认后执行）
3) 退出
```

## 安全说明

- 检测过程只读，不需要管理员权限
- 修复操作需输入 `y` 确认，且仅关闭代理开关
- 不修改 DNS、路由、hosts、进程、扩展
- 不联网，不下载，不上传任何数据
- 修复完全可逆
