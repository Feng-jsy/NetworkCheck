# NetworkCheck

快速地，本地网络检测和简单修复

排查 macOS / Windows 上因加速器、VPN、代理软件异常退出而残留的网络问题。

**当前版本：v1.1**

## 项目文件

- `Mac/NetworkCheck.command` — macOS 主程序（bash，双击运行）
- `Windows/NetworkCheck.py` — Windows 主程序（Python 3.8+，纯标准库）

## 使用方法

### macOS

直接双击运行。首次打开如被 Gatekeeper 拦下，右键 → 打开。

### Windows

需先安装 Python 3.8+（python.org，安装时勾选 Add Python to PATH），然后：

```
python NetworkCheck.py
```

目前仓库未提供预编译的 `.exe`。如需独立可执行文件，可在 Windows 环境下自行打包。

## 功能说明

启动后自动执行检测，检测完成后显示菜单：

```
1) 再次检测
2) 修复（先展示动作，确认后执行）
3) 退出
```

### macOS：12 项检查

系统代理、各网络服务代理、VPN 配置、默认路由、虚拟接口、DNS、代理端口监听、加速器/代理进程、其他可疑进程、网易 UU 守护项、/etc/hosts、系统扩展与网络扩展。

其中进程一项会额外列出该进程监听的所有端口，自定义端口也不会漏。

### Windows：14 项检查

系统代理、各网络服务代理、WinHTTP 代理、环境变量代理、VPN 配置、默认路由、虚拟网卡、DNS 配置、代理端口监听、相关进程、hosts 文件、启动项、系统扩展、网络扩展。

## 安全说明

- 检测过程只读，不需要管理员权限，不改任何东西
- 修复前先完整展示将要执行的动作，输入 `y` 确认后才执行
- 修复包含两件事：**终止匹配到的加速器/代理进程**、关闭网络服务的代理开关
- 终止进程时自动跳过系统路径下的进程（`/System/`、`/usr/`、`/sbin/`、`/bin/`、`/Library/Apple/`）
- 只在需要关代理时才请求管理员密码；单纯终止进程不需要
- 不修改 DNS、路由、hosts 文件、系统扩展
- 不联网，不下载，不上传任何数据
- 修复可逆：重新打开加速器即可，但**未保存的加速器配置可能丢失**

## 更新日志

### v1.1

- macOS：修复能力扩展，除关闭代理外，可终止加速器/代理进程（先普通终止，失败再强制终止，随后复查存活）
- macOS：进程检测重写，改用 `ps -axo pid=,args=` 取完整命令行，并过滤系统路径，避免误伤系统进程
- macOS：新增「其他可疑进程」检查（Proxifier、Netch 等）
- macOS：代理进程会额外列出其监听的所有端口，不只常见端口
- macOS：管理员密码只在需要关闭代理时才申请
- 检查项由 11 节增加到 12 节，文案精简

### v1.0

- 首次发布
- 支持 Windows 与 macOS 双平台
- 覆盖 14 项网络配置检测：系统代理、各服务代理、WinHTTP、环境变量代理、VPN、默认路由、虚拟网卡、DNS、代理端口、相关进程、hosts、启动项、系统扩展、网络扩展
- 提供确认式修复机制，修复前展示完整命令，用户确认后执行
- 修复范围仅限代理开关，不涉及其他网络配置
